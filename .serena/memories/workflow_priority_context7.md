# Protocolo de Prioridad Context7

## REGLA OBLIGATORIA
**SIEMPRE** usar Context7 PRIMERO para cualquier consulta sobre:
- Bibliotecas, frameworks, APIs
- Documentación técnica
- Ejemplos de código
- Configuraciones de herramientas

## Flujo Correcto
1. Context7 → Documentación oficial actualizada
2. WebSearch → Solo si Context7 no tiene la info
3. Experiencia propia → Como último recurso

## Casos de Uso Context7
- "¿Qué puedo hacer con X biblioteca?"
- "¿Cómo configurar Y herramienta?"
- "Ejemplos de implementación de Z"
- "Documentación de uvx, mcp-server-git, etc."

## Recordatorio Permanente
Usuario espera que Context7 sea la PRIMERA opción para documentación técnica.
NO usar WebSearch primero a menos que sea información muy específica del proyecto actual.
